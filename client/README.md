# Distortion Grid

Daily competitive Discord Activity puzzle.

## Local setup
1. Copy `.env.example` to `.env`
2. Fill in your local values
3. Run `npm install`
4. Run `npm run dev`

## Railway
- Build command: `npm run build`
- Start command: `npm start`
- Add PostgreSQL
- Add the variables from `.env.example`

## Production plan
- Discord Activity frontend
- Express backend
- PostgreSQL shared leaderboard and official attempts
- Discord bot result posts
- Admin access tied to Discord user ID
